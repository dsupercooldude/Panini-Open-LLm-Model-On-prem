## 2. Release `v5.7-alpha (SVN-r407.1-alpha)` Deliverables: Production Architecture Phase 1

1. **Dual-Sided Input & Output Guardrails (`runInputGuardrailScan` & `runOutputGuardrailScan`)**:
   - **Input Gateway**: Automatically redacts sensitive PII (`Credit Card`, `SSN`, `Email`, `Phone`, `API Key`) into `[REDACTED_PII:*]` tokens and blocks prompt-injection / system-override attacks (`SYSTEM_PROMPT_OVERRIDE`, `CREDENTIAL_EXFILTRATION`, `SQL_COMMAND_INJECTION`) before any model sees the prompt.
   - **Output Gateway**: Verifies claim-grounding against retrieved sources (`groundingScorePct`), checks policy compliance, and scrubs any leaked output PII prior to rendering.

2. **Bounded Agent Orchestrator (`executeBoundedAgentOrchestrator`) & HITL Approval Gate**:
   - Executes a bounded **Plan &rarr; Act &rarr; Observe** loop with configurable `maxStepsAllowed` (default `6`) and `timeoutMs` (default `8,000ms`), model-router tier assignment (`small_fast_8b`, `vision_ocr_12b`, `large_reasoning_72b`, `sandbox_tool_runner`), and a **Temporal.io + n8n Enterprise Workflow DAG** view.
   - Pauses automatically (`paused_for_hitl`) with an interactive **Human-in-the-Loop (HITL) Approval Card** (`Approve & Execute` / `Reject`) before risky actions such as posting journal entries to `mcp://erp` or dispatching external executive emails via `mcp://email`.

3. **End-to-End "Upload Receipt &rarr; Build Expense Deck" Pipeline**:
   - **Vision OCR & Reconciliation (`runReceiptVisionOcrAndReconcile`)**: Uses `PaddleOCR-v4 + Whisper-Large-v3` messy-input adapters to extract line items, tax, and service charges and verify exact arithmetic (`reconciledExact: true`, e.g., `AED 800.00`).
   - **Sandboxed Tool Builders (`buildSandboxedExpenseDeckBundle`)**: Executes inside `gVisor (runsc)` or `Firecracker MicroVM` using `python-pptx`, `python-docx`, `openpyxl`, and `%PDF-1.4` with selectable **Brand Style Templates** (`Executive Slate`, `Sovereign Gold`, `Swiss Minimal`) so the LLM never writes raw binary files directly.
