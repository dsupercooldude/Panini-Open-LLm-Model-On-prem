## 2. Release `v5.7-alpha (SVN-r407.1-alpha)` Deliverables: Production Architecture Phase 1

1. **Dual-Sided Input & Output Guardrails (`runInputGuardrailScan` & `runOutputGuardrailScan`)**:
   - **Input Gateway**: Automatically redacts sensitive PII (`Credit Card`, `SSN`, `Email`, `Phone`, `API Key`) into `[REDACTED_PII:*]` tokens and blocks prompt-injection / system-override attacks (`SYSTEM_PROMPT_OVERRIDE`, `CREDENTIAL_EXFILTRATION`, `SQL_COMMAND_INJECTION`) before any model sees the prompt.
   - **Output Gateway**: Verifies claim-grounding against retrieved sources (`groundingScorePct`), checks policy compliance, and scrubs any leaked output PII prior to rendering.

2. **Bounded Agent Orchestrator (`executeBoundedAgentOrchestrator`) & HITL Approval Gate**:
   - Executes a bounded **Plan &rarr; Act &rarr; Observe** loop with configurable `maxStepsAllowed` (default `6`) and `timeoutMs` (default `8,000ms`), model-router tier assignment (`small_fast_8b`, `vision_ocr_12b`, `large_reasoning_72b`, `sandbox_tool_runner`), and a **Temporal.io + n8n Enterprise Workflow DAG** view.
   - Pauses automatically (`paused_for_hitl`) with an interactive **Human-in-the-Loop (HITL) Approval Card** (`Approve & Execute` / `Reject`) before risky actions such as posting journal entries to `mcp://erp` or dispatching external executive emails via `mcp://email`.

3. **End-to-End "Upload Receipt &rarr; Build Expense Deck" Pipeline**:
   - **Vision OCR & Reconciliation (`runReceiptVisionOcrAndReconcile`)**: Uses `PaddleOCR-v4 + Whisper-Large-v3` messy-input adapters to extract line items, tax, and service charges and verify exact arithmetic (`reconciledExact: true`, e.g., `AED 800.00`).
   - **Sandboxed Tool Builders (`buildSandboxedExpenseDeckBundle`)**: Executes inside `gVisor (runsc)` or `Firecracker MicroVM` using `python-pptx`, `python-docx`, `openpyxl`, and `%PDF-1.4` with selectable **Brand Style Templates** (`Executive Slate`, `Sovereign Gold`, `Swiss Minimal`) so the LLM never writes raw binary files directly.

## 3. Release `v5.7-beta (SVN-r407.2-beta)` Deliverables: Production Architecture Phase 2 (KISS UI)

1. **Upgraded Knowledge & Data Pipeline (`runHybridKnowledgePipelineV57`)**:
   - **OCR Table Extraction**: Extracts structured multi-column tables (`TBL-EXP-2026-Q3` via `PaddleOCR-v3 Table-Structure` at `99.2%` confidence and `TBL-POLICY-CAPS-2026` via `Camelot-PDF-Lattice` at `99.6%` confidence) with row/column headers and source page provenance.
   - **Rich Chunk Metadata**: Every indexed chunk includes `documentTitle`, `connectorSource` (`SharePoint`, `ERP`, `CRM`, `Email`, `Ticketing`, `CodeSandbox`), `classification` (`PUBLIC`, `INTERNAL`, `CONFIDENTIAL`, `RESTRICTED_EXEC`), `allowedRoles`, `sectionHeader`, `pageNumber`, `tokenCount`, and `ingestedAt`.
   - **Hybrid Search + Cross-Encoder Reranker**: Combines lexical **BM25 Keyword Score** (`bge-bm25-lexical-v2`) with **Vector Cosine Similarity** (`bge-large-en-v1.5`, 1024-dim) via `0.35 * BM25 + 0.65 * Vector`, then re-orders authorized chunks using **`bge-reranker-v2-m3-cross-encoder`**.

2. **Permission-Aware Retrieval & Document ACL Audit Badge**:
   - Enforces strict role-based and classification-based filtering across four canonical ACL roles (`Viewer`, `Analyst`, `Developer`, `Admin`), with automatic normalization from legacy workspace roles via `normalizeToAclRole()`:
     - **`Viewer`**: Authorizes `2/6` chunks (`PUBLIC` only); filters `4` restricted chunks (`INTERNAL`, `CONFIDENTIAL`, `RESTRICTED_EXEC`).
     - **`Analyst`**: Authorizes `4/6` chunks (`PUBLIC`, `INTERNAL`, and Finance `CONFIDENTIAL`); filters `2` chunks (`DOC-CONF-ENG-302` & `DOC-EXEC-401`).
     - **`Developer`**: Authorizes `4/6` chunks (`PUBLIC`, `INTERNAL`, and Engineering `CONFIDENTIAL`); filters `2` chunks (`DOC-CONF-FIN-301` & `DOC-EXEC-401`).
     - **`Admin`**: Authorizes `6/6` chunks (including `RESTRICTED_EXEC`); filters `0` chunks.
   - Surfaces a compact **ACL Audit Badge** (`data-testid="acl-audit-badge"`) and live role switcher (`data-testid="card-acl-role-selector"`) showing authorized vs. redacted document counts and audit reasons.

3. **Formal MCP Server Registry (`buildMcpServerRegistryV57` & `evaluateMcpToolAccessV57`)**:
   - Registers 6 enterprise MCP servers with scoped per-user OAuth2/Vault/mTLS tokens and least-privilege RBAC enforcement:
     - `mcp://sharepoint` (`search_documents`, `fetch_table_chunks`, `upload_approved_deck`)
     - `mcp://erp` (`read_cost_center`, `validate_budget_cap`, `post_journal_entry`)
     - `mcp://crm` (`lookup_account_opportunity`, `link_client_expense`, `update_deal_notes`)
     - `mcp://email` (`search_receipt_threads`, `draft_reimbursement_memo`, `send_executive_email`)
     - `mcp://ticketing` (`create_compliance_ticket`, `check_approval_sla`, `resolve_exception_ticket`)
     - `mcp://code-sandbox` (`render_pptx_deck`, `render_docx_memo`, `render_xlsx_ledger`, `render_pdf_voucher`)
